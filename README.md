# A (to be) bare-bones analyzer for the game Broken Ranks

Yet to be implemented, analyzer for the game Broken Ranks.
Inspired by [BrokenHUD](https://github.com/Brok3nSign/BrokenTools/releases).
Will definitely be way more primitive than the one it's inspired on, because I just can't be bothered to add all those features.
Unless you value FOSS or have troubles setting up BrokenHUD on your linux system, then you should use [it](https://github.com/Brok3nSign/BrokenTools/releases) instead.
